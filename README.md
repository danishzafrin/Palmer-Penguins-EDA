# Exploratory Data Analysis: Palmer Penguins

## Overview
An EDA investigating physical distinctions across three penguin species 
and their geographic distribution across three islands.

## Key Findings
- Gentoo penguins are distinctly larger in flipper length and body mass
- Adelie and Chinstrap are similar in size but separable by culmen length
- Culmen length is the strongest biological differentiator between species

## Tools Used
Python, Pandas, Seaborn, Matplotlib

## Dataset
Palmer Penguins dataset (penguins_size.csv)
